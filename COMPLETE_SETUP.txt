🚀 THREE STEPS TO LAUNCH
═══════════════════════════════════════════════════════════════════════════════

STEP 1: TEST LOCALLY (5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. cd f:/Projects/portfolio/ui
2. npm run build
3. npm run preview
4. Open http://localhost:4173

If no errors, proceed to Step 2.


STEP 2: PUSH TO GITHUB (10 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. cd f:/Projects/portfolio/ui
2. git init
3. git add .
4. git config user.name "Mohitya06"
5. git config user.email "your-email@example.com"
6. git commit -m "Initial portfolio"
7. git branch -M main
8. git remote add origin https://github.com/Mohitya06/mohitya-portfolio.git
9. git push -u origin main

Code is now on GitHub, proceed to Step 3.


STEP 3: DEPLOY TO VERCEL (5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Visit https://vercel.com/dashboard
2. Sign in with GitHub
3. Click "New Project"
4. Select "mohitya-portfolio" repository
5. Click "Deploy"
6. Wait 1-2 minutes
7. Your site is LIVE at https://mohitya-portfolio.vercel.app

🆘 QUICK FIXES

  - Clear cache: Ctrl+Shift+Delete

  - Verify format (jpg/png)
