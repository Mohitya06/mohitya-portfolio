# Mohitya Portfolio - UI

A modern, responsive portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Features

- ⚡ **Fast Development** - Powered by Vite for instant HMR
- 🎨 **Beautiful Design** - Tailwind CSS for modern styling
- ✨ **Smooth Animations** - Framer Motion for engaging interactions
- 📱 **Fully Responsive** - Mobile-first design approach
- 🎯 **SEO Optimized** - Meta tags and semantic HTML
- 💼 **Professional** - Showcase your work and skills effectively

## 📋 Project Structure

```
src/
├── components/
│   ├── Navbar.jsx          # Navigation component
│   ├── Footer.jsx          # Footer component
│   └── ...
├── sections/
│   ├── Hero.jsx            # Hero section
│   ├── About.jsx           # About section

│   ├── portfolio.js        # Portfolio data

```

## 🛠️ Tech Stack

- **Frontend Framework**: React 18.3.0
- **Build Tool**: Vite 5.3.4
- **Styling**: Tailwind CSS 3.4.6
- **Animations**: Framer Motion 11.3.0
- **Icons**: React Icons 5.2.0
- **Fonts**: Inter, JetBrains Mono (Google Fonts)

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mohitya06/mohitya-portfolio.git
   cd mohitya-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

   The app will be available at `http://localhost:5173`

## 🔨 Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally

## 🎨 Customization

### Update Portfolio Data
Edit `src/data/portfolio.js` to customize:
- Personal information
- Skills and technologies
- Project showcase
- Experience timeline
- Contact information

### Change Styling
- **Colors**: Modify `tailwind.config.js`
- **Typography**: Update font settings in `index.html`
- **Custom CSS**: Add styles to `src/index.css`

### Modify Profile Image
Replace the image at `src/data/profile-image.jpg` with your own profile picture.

## 📤 Deployment

### Deploy to Vercel (Recommended)
```bash
npm install -g vercel
vercel
```

### Deploy to Netlify
```bash
npm run build
# Drag and drop the 'dist' folder to Netlify
```

### Deploy to GitHub Pages
```bash
npm run build
# Push the 'dist' folder to gh-pages branch
```

See [Deployment Guide](#deployment-guide) for detailed instructions.
