## 🚀 Quick Launch (40 Minutes)

```bash
# Step 1: Test locally (5 min)
npm run build
npm run preview

# Step 2: Push to GitHub (10 min)
git init
git add .
git config user.name "Mohitya06"
git config user.email "your-email@example.com"
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/Mohitya06/mohitya-portfolio.git
git push -u origin main

# Step 3: Deploy to Vercel (5 min)
# Visit https://vercel.com/dashboard
# Import repository → Click Deploy

# Step 4: Customize (15 min)
# Edit src/data/portfolio.js
# Add your content

# Step 5: Verify (5 min)
# Test live URL and share!
```
