PATH 2: GITHUB PAGES (Free - 10 minutes)
─────────────────────────────────────────────────────────────────────────
1. Build: npm run build
2. Deploy: git subtree push --prefix dist origin gh-pages
3. Go to: https://github.com/settings/pages
4. Select: gh-pages branch
5. Save & wait 2 minutes

Result: https://Mohitya06.github.io/mohitya-portfolio


PATH 3: NETLIFY (Easy - 5 minutes)
─────────────────────────────────────────────────────────────────────────
1. Visit: https://netlify.com
2. Sign in with GitHub
3. Click: New site from Git
4. Select: mohitya-portfolio
5. Click: Deploy
6. Wait 2 minutes

Result: [your-site].netlify.app
